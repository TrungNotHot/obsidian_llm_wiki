# Easy Read & Architecture Guides (`wiki/easy_read/`)

This directory contains stakeholder-accessible architecture guides, end-to-end workflows, and system blueprints in clear, structured language with visual diagrams.

---

## 📐 Conventions & Rules (per [[SCHEMA]])

1. **Purpose**: Provide high-level, human-readable walkthroughs of systems, pipelines, and workflows.
2. **Standard Frontmatter**:
   ```yaml
   ---
   title: "Guide Title"
   created: YYYY-MM-DD
   updated: YYYY-MM-DD
   type: guide
   tags: [guide, easy-read, architecture]
   confidence: high
   contested: false
   status: published
   ---
   ```
3. **Connectivity**: Every guide must cross-link to relevant concepts and entities.
